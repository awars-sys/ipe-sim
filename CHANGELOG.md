# Changelog

## 7.0 · 2026-10-13

Taylor Watterson's guided flow, built on the v5.0 template. Source: "IPE Maya Change Log: v5.0 to Taylor's Prototype".

From Taylor's prototype
- One continuous group chat: Team introductions (group name, Start over), then Margaret (practice), Lucy and Brian in fixed order. The next case opens only after the debrief.
- Four steps per case: Roles, Referrals (top 2 and why), Tobacco plan (one A per reply), Joint note (Maya drafts, group replies "approved").
- Taylor's Maya rules: 1 to 2 sentences, one question, no praise or grading, no names, explains dental terms, volunteers dental findings, scripted dental-student and pharmacy-expert questions, practice-case EHR coaching, mental health as referral only.
- Taylor's chart content: dental findings removed from the chart (ask Maya), acetaminophen added for Brian, readiness row first, short reference ranges, cigarettes per day.
- Finish and debrief after 4 group messages, with confirmation. Four-part debrief by a faculty-facilitator prompt.
- Final report from all three cases, grouped by question; edit, redraft, sign-off names and approval box; Copy for Canvas with transcript.
- Resources tab: 5 As, 5 Rs, 5 Ds, NRT dosing table, 8 links. Optional class code. Chat autosaved in the browser.

Kept from v5.0 (by request)
- v5.0 look: navy EHR, storyboard, chart menu, step timeline.
- Yellow question box (now shows the current step and the current A), "Ask Maya for a hint" (3 per case, points to where to look), highlighter (highlights go into the copied transcript).
- Server-side function with cached system prompt, structured replies and the offline backup.

New in 7.0 (faculty to confirm)
- NRT dose: Maya asks Margaret's starting strengths at Assist; key expects patch 21 mg (14 mg defensible) and lozenge 4 mg.
- Brian: short-acting NRT for breakthrough cravings with varenicline (lozenge easier than gum with his tooth pain), nasal spray a poor fit with nasal polyps and rhinitis, montelukast boxed-warning mood and sleep check.
- Agreed message rules: greetings, "I don't know", chart questions, off-topic and answer requests all get a redirect or hint. The "glitch" message is gone.
- Backup Maya rewritten to walk the 4 steps; self-check list and own-words report when Claude is down.
- Cost: 1-hour cached system prompt, cached conversation, current case only. Faculty keys moved off the public page.

Fixes from the v5.0 bug list now resolved: off-topic messages using tries, the glitch reply, Part A, early jump to the next question, ungrammatical feedback, Q4 grading, cross-section points, praise for weak answers, invented names, badge always showing, message sent twice.
